# LoveLive! 厨力大比拼

面向手机浏览器的纯静态淘汰赛网页。第一版仅包含 65 人全员随机模式：两人先进行资格赛，胜者挑战一名资格赛轮空者，产生完整 64 人首轮。开局公布完整命运签表，并支持角色搜索、潜在路线高亮和实时赛况。所有比赛数据保存在浏览器本地，不上传服务器。

## 本地打开

直接双击项目最外层的 `index.html` 即可游玩。网页不依赖服务器、第三方包或构建步骤。

## 头像替换

`image` 文件夹内的图片已经按角色姓名接入选择卡、签表、冠军页和结果分享图，65名角色均已配置头像。

结果分享图使用 `dist/share-avatar-data.js` 中的内嵌头像，以兼容直接双击本地 HTML 后导出 PNG。替换头像后运行 `node scripts/build-share-avatar-data.mjs` 即可重新生成该文件。

六个团体的图片标识位于 `image/logos`，用于替代角色卡、签表和结果页中的团体文字标识。

签表页可以直接导出完整高清树状图；比赛结束后可以另存包含全部晋级结果的冠军晋级树。树状图按约 3630 × 2640 像素生成，不受手机屏幕滚动范围限制。为兼容直接双击打开的本地 HTML，树状图使用纯 Canvas 文字与线路绘制，不嵌入可能触发本地文件安全限制的外部图片。

桌面浏览器打开签表时会提供“网页版 / 手机版”手动切换。网页版使用宽屏布局，并提供缩小、恢复 100%、放大和适应全局控制；手机版恢复 720px 居中窄版。首页、对决和结果页始终保持适合阅读的窄版布局。
